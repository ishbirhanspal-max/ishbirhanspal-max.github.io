How PDF Compression Works

PDF files can be large for several reasons: embedded high-resolution photos, embedded fonts, metadata, and redundant cross-reference data. OptiPixel's PDF compressor uses two complementary strategies:

  1. Image Re-encoding: Most PDF size comes from embedded images. We re-render each page using PDF.js at the selected quality level and re-embed the images at a lower JPEG quality ratio, reducing image data by 50–80%.
  2. Stream Re-packaging: We use PDF-lib to reconstruct the PDF document structure, removing redundant metadata, unused objects, and deprecated cross-reference tables — a process called linearization.

The result is a visually identical (or near-identical) PDF at a dramatically smaller file size, produced entirely in your browser without any server upload.

Compression Level Guide

Screen (Lowest File Size)

Images are re-encoded at 50–60 DPI with high compression. Ideal for web previews, online submissions, and situations where file size matters most. Text remains readable but images lose fine detail.

eBook (Recommended)

A balanced trade-off at ~120 DPI. The default setting. Produces files 50–60% smaller while maintaining readable photographs and crisp text. Perfect for email attachments (under 10 MB limit) and cloud storage.

Printer Quality

Re-encodes at ~200 DPI. Good for documents you will print at home or at a standard office printer. Reduces file size by 30–40% while preserving excellent print clarity.

Prepress (Maximum Quality)

High-fidelity re-encoding at ~300 DPI. Best for archival, professional printing, and graphic design documents. Minimal compression, maximum color accuracy.

Frequently Asked Questions

Does compressing a PDF remove text or fonts?

No. The tool does not strip fonts or text content. Text layers are preserved exactly as they are in the original PDF. Only embedded image data is re-encoded at a lower quality — and only when you select the Screen or eBook mode.

Will my digital signatures survive compression?

Because the tool re-constructs the PDF document, existing digital signatures will be invalidated (the byte-range hash changes). Do not compress PDFs that need to retain legally valid signatures. Use Printer or Prepress mode if signature preservation is critical.

How large a PDF can this tool handle?

There is no hard size limit, but very large PDFs (50+ MB with hundreds of high-res photos) may take 30–60 seconds to process. Performance depends on your device's RAM and CPU speed. Modern laptops handle 100-page PDFs in under 20 seconds.
