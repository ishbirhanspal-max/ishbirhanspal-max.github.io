2. Architectural Description of Service

OptiPixel Studio provides an advanced suite of free, browser-based digital media and document editing utilities. Key tools provided include, but are not limited to:

  • Image Processing: Lossless and lossy image compression (JPG, PNG, WebP), format conversion, image resizing, dimensions scaling, and batch watermarking.
  • PDF Studio: Client-side PDF viewing, visual text annotations, page merging, splitting, high-ratio compression, image-to-PDF conversion, and AES-128 document encryption.
  • Generative & Barcode Utilities: Permanent static 2D QR code generation (URL, text, Wi-Fi, vCard, WhatsApp) and linear barcode generation (Code 128, EAN, UPC).
  • AI & Computer Vision: Machine-learning background removal via in-browser MediaPipe models, optical character recognition (OCR) text extraction via Tesseract.js, and passport photo dimensioning.
Zero-Cloud, Client-Side Guarantee: Unlike traditional SaaS file conversion websites, OptiPixel Studio utilizes modern HTML5 Canvas, Web Workers, WebAssembly (Wasm), and browser memory threads. All file manipulation, compression, and analysis occurs strictly on your local client device. Your images, documents, credentials, and text are never uploaded to our servers, never stored in a cloud database, and never processed remotely.
