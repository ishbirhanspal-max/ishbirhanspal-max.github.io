What Makes a Password Truly Strong?

Password strength is measured by entropy — the number of bits of unpredictability. The formula is: Entropy = log₂(pool_size ^ length). A 20-character password using all 4 character types (uppercase, lowercase, numbers, symbols) has a pool of 94 characters, giving over 130 bits of entropy — which would take billions of years to brute-force even with the most advanced quantum computers.

Entropy Guidelines

  • < 40 bits — Very Weak: Cracked in seconds by modern hardware
  • 40–60 bits — Weak: Vulnerable to targeted dictionary attacks
  • 60–80 bits — Fair: Good for low-value accounts
  • 80–100 bits — Strong: Suitable for financial accounts and email
  • 100+ bits — Very Strong: Cryptographically uncrackable

How OptiPixel Password Generator Works

This tool uses window.crypto.getRandomValues() — the W3C Web Cryptography API — to source randomness directly from your operating system's secure entropy pool (same source used by OpenSSL and system security utilities). This is fundamentally different from weaker Math.random() which is not cryptographically secure.

Privacy Guarantee

Your generated passwords are computed entirely in JavaScript inside your browser tab. No network request is ever made. The passwords exist only in your browser's RAM and are automatically erased when you close the tab or navigate away. We do not log, store, or transmit any generated password.

Frequently Asked Questions

How many passwords can I generate?

Unlimited. There are no quotas, no daily limits, and no registration required. Click "Generate" as many times as you like.

What is the best length for a secure password?

We recommend at least 16 characters for regular accounts and 20+ characters for email, banking, and cloud service accounts. If you are using a password manager (which we recommend), use 32+ characters since you only need to remember one master password.

Should I use a password manager?

Yes, absolutely. Tools like Bitwarden (free & open-source), 1Password, or Dashlane let you store and auto-fill unique strong passwords for every website without memorizing them. Generate a different password for every site using this tool, then store it in your manager.
